# Reporting security concerns

Do not put credentials, private code, session URLs, or exploit details in a public issue. Use this repository's private vulnerability reporting option under **Security → Report a vulnerability** when available. If it is unavailable, open a public issue that only asks for a private contact route, without sensitive details.

Revu 0.5.0 is an unsigned developer preview. Keep the local server bound to loopback, do not expose it via a public tunnel, and inspect exported context before sharing it. Review signals are heuristic and do not certify that a repository is secure.
